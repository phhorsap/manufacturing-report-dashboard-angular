📊 Production Dashboard | Angular + Chart.js
A high-performance, responsive Production Reporting Dashboard built with Angular and Chart.js. This project focuses on clean data visualization, real-time metrics, and a modern UI/UX for industrial monitoring.

✨ Key Features
Real-time KPI Tracking: Instant visualization of Production Quantities, Scrap Rates, and Energy Consumption.

Interactive Data Visualization: Dynamic Bar and Doughnut charts with custom tooltips and animations via Chart.js.

Visual Hierarchy Design: Color-coded KPI cards (Fact, Quantity, Scrap, Energy, Cost) for quick status assessment.

Responsive SCSS Architecture: Modular styling using SCSS variables and mixins for a consistent look across all screen sizes.

Performance Optimized: Light-weight components designed for fast rendering of complex datasets.

🛠️ Tech Stack
Frontend: Angular 17+ (Latest Features)

Charts: Chart.js / ng2-charts

Styling: SCSS (Sass), Material Design Icons

Logic: TypeScript (Strongly Typed Models)
Clone & Install: npm install

Start Mock API: npm run server (runs on port 3000)

Start Dashboard: npm start

npm install -g @angular/cli
